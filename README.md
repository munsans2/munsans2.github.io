## 확정된 배치 내용 (사용자 제공 내용)

| 부분 | 기준 내용 |
|---|---|
| 왼쪽 벽면 | 큰 목재 수납장 2개, 낮은 목재 수납장 4개 |
| 낮은 목재장 첫 번째 | 안전용품 보관 |
| 왼쪽 벽면 미니벽 뒤 | 짧은 돌출벽 1곳과 철제 2단 수납장 2개, 기존 목재장과 같은 서랍 방향 |
| 칠판 아래/뒤쪽 벽면 | 큰 유리문 보관장 3개, 옆 작은 보관함 1개 |
| 오른쪽 창가 | 보관함 14줄(2줄=1모듈 → 7모듈) |
| 창가 가까이 | 태블릿 보관함 1개 |
| 출입문 | 2곳, 목재 보관장 삭제하지 않고 조정 |

현재 치수/보관장 번호, 모듈의 문 위치와 세부 선반 수는 임시입니다. 정확한 실측 전 검증된 사실처럼 표시하지 마세요.

## 배치 코드 수정하기

`science1/layout.js`의 `cabinets` 배열 항목에서 `x`, `z`, `rot`, `width`, `height`, `depth`를 변경합니다.
- `x`: 왼쪽(-)·오른쪽(+), `z`: 칠판 쪽(-)·교실 입구 쪽(+)
- `rot: 90`: 왼쪽 벽면장, `rot: -90`: 오른쪽 벽면장, `rot: 0`: 칠판 쪽 벽면장
- `kind`: `wood`(목재 여닫이), `glass`(유리 슬라이딩), `drawer`(서랍식), `tablet`(태블릿장), `metal2`(철제 2단 서랍), `twotier`(기존 2단 양문형)
- `inventory`: 물품 이름과 관리번호만 연결. 확인되지 않은 수량/선반은 `null` 유지.

사진은 더 정확한 배치 모델링을 위한 참고용이며 GitHub 저장소에 올릴 필요 없습니다.
